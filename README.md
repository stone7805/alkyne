# 炔烃四类通关游戏 V3.4

## 上传到 GitHub Pages

1. 将本文件夹中的 `index.html` 和 `parser.html` 放在仓库发布目录的同一层。
2. GitHub Pages 发布后，学生访问仓库网址即可开始游戏；教师在同一网址后加 `/parser.html` 打开学习记录解析页。
3. 如果沿用原来的仓库，只需替换 `index.html`，同时新增或替换 `parser.html`。网址不变，原二维码仍可继续使用。

## 手机 QQ 提交

- 学生在阶段页或通关成绩页点击“复制 QQ 简报”或“复制完整记录短码”。
- 页面会再次确认内容包含班级、姓名和 10 位学号；确认后才复制。
- 教师把学生发来的短码粘贴到 `parser.html`，点击“解析并还原表格”。
- 校验码用于发现复制时的缺字、错字或截断；短码不是加密，也不是服务器防作弊凭证。

## 版本与兼容

- 游戏版本：V3.4；存档协议：3.4-r1。
- V3.3、V3.2 旧进度会尝试安全迁移，旧存档不会被删除。
- CSV 仍为 20 列课堂分析口径；手机端优先使用 QQ 简报和短码。
- 页面为单文件离线游戏，解析页也可离线运行；GitHub Pages 不会自动汇总学生成绩。
